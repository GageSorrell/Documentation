# Authoring guidance

Prefer short sections with descriptive headings, runnable code, and links to
the next task. Keep examples self-contained and state which package and
version they target. Use fenced code blocks with a language tag.

For MDX, use the site's supported callout, tab, code, and example primitives.
Unsupported JSX or raw HTML will not be available to agent-readable output in
later build stages.
