# Native commands

- `sorrell-docs story init` creates an app and an initial story.
- `sorrell-docs story dev` starts the scoped Expo process.
- `sorrell-docs story generate --platform android|ios|web|all` exports a target.
- `sorrell-docs story verify` typechecks and exports the target.

Interrupting `dev` must terminate the Expo and Storybook child processes.
