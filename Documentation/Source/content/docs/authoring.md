## Keep the next action obvious

Start pages with the outcome a reader came for. Use headings to divide the work into steps, and keep examples close to the explanation that gives them meaning.

### Markdown first, MDX when needed

Plain Markdown is the default. MDX is available when a page needs an interactive React example or a richer content primitive. Keep those additions local to the page so the content remains portable.

### Copy for LLM

Every article places a Copy for LLM control at the top of the reading surface. The copied document includes the title, canonical URL, page context, and rendered source content in a predictable format.
