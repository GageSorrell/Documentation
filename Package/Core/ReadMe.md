# `@sorrell/docs-core`

Browser-safe Effect schemas, configuration normalization, diagnostics, and stable domain models for Sorrell documentation tooling.

The package intentionally has no Node.js or platform-specific dependencies. It is the shared contract used by the CLI, generators, websites, and Storybook integration.
