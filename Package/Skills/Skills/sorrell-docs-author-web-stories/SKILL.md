# Author web Storybook documentation

Use `sorrell-docs storybook init`, `dev`, `build`, and `verify` for the web
Storybook package. Add typed CSF stories with controls, autodocs-friendly
args, and stable imported assets. Use `sorrell-docs story` for native content.
