# Create native Storybook

Use `sorrell-docs story init --target <directory> --kind development` for the
exhaustive app or `--kind demonstration` for the public-API showcase. Use
`sorrell-docs story dev`, `generate --platform all`, and `verify` to operate
the app.

Read [Native Apps](references/NativeApps.md) and
[Commands](references/Commands.md).
