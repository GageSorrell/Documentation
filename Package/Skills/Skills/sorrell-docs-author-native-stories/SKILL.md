# Author native Storybook documentation

Use `sorrell-docs story add story|example|article --target <app> --name <Name>`
for native content. Stories live under `Stories`, examples under `Examples`,
and articles under `Articles`. Run `sorrell-docs story verify` afterward.

Read [Native Authoring](references/NativeAuthoring.md) and
[Articles](references/Articles.md).
